# Dashboard educacional (Fase 7)

Scaffold React + Vite + TypeScript.

## Desenvolvimento

```powershell
cd frontend
npm install
npm run dev
```

Build estático servido pelo FastAPI (quando configurado):

```powershell
npm run build
```

Saída esperada em `frontend/dist/` — montar em `/dashboard` após calibração dos sinais.

**Pré-requisito:** módulos calibrados; disclaimer permanente; sem rótulos emocionais por rosto.
